## 现象（D7 四臂因果日，2026-08-25~26 跑完；R3 修正）

- 重复集 20 任务配对：**X2（当日 842 卡库+注入）0.268 vs X1（D1 冻结 235 卡库+注入）0.446**，
  双侧 sign-flip 精确置换（2^20 枚举）p=0.0425 < 0.05（预注册主检验，显著为负）；
  **剔 3 极端任务后 −0.072、p=0.309 不显著**——效应集中于少数灾难任务，不能推广为稳定负效应。
- 对照：X3（当日库无注入）0.445 ≈ X4（冻结库无注入）0.434 → 机器与题目无偏；
  冻结库注入效应 X1−X4=+0.012 ≈ 0；sanity X3−X4=+0.011（tier ok）；
  交互作用 (X2−X3)−(X1−X4)=−0.189；DiD=−0.083（不显著）。
- 复制判定：D2 +0.093 与 D7 不同号；合并检验 p=0.42 不显著。
- 实例偏置 V=−0.083 → C 级归档（D2/D7 两次反号，零附近高方差摆动，相互不支持稳定偏置）。
- 敏感性：score_simple −0.128 / 中位数 −0.057，方向一致为负；drop-3 是 post-hoc 敏感性分析，非预注册。
- 日漂移 ±0.07（冻结两臂 D2→D7 同库同题自涨 +0.069/+0.076）——跨日比较的固有噪声幅度；n=20 对 drop-3 量级功效仅约 0.16。
- 泄漏 0/8；Kimi 双裁判 D2/D7 两次 consistent（同日一致性口径，不跨日锚定）。
- 门控：请求级/任务级 MissedEscalationRate 均为 100%（所有失败均未升级），升级次数为 0 不等于健康。

## 归因（R2 修订：四个因子，因果强度如实标注）

1. **攻略卡/注入计划致害（风险因子，个案级硬证据）**：task_00065 注入集 D6→D7 **仅换入 1 张**
   攻略卡（exp-632319a4，procedure 含题目未要求的 JSON 交付物）→ 9B 照卡写脚本→调试漩涡
   →30 回合耗尽→README 未写→0 分（同日冻结臂 0.90 / D6 未命中此卡 0.81）。注入稳定化更正后
   该个案成为"单卡换入"自然实验。Oracle task_00060 同构：裸考 0.80 → 注入教师完美攻略 0.00
   （为照攻略偏离任务精确交付要求，文件名带时间戳被 hybrid 罚则清零）——**注入行为本身可致害**。
   推论边界：205 张攻略卡中致害率未知，个案→系统无定量支撑。
2. **碎碎念卡污染（风险因子，量级可信）**：自言自语片段成卡约 41~110 张（识别规则未固化，
   title 正则 41 / 并集规则 89），样例 quality 0.50~0.73；进入过注入的 12 张复用 1421~4383 次。
   跨任务注入有诱导嫌疑（task_00002 x2 走脚本路线超时），但同注入 x1=0.78——**既非充分也非必要**。
3. **9B 执行方差（放大器，标尺待 T9）**：task_00002 两臂注入逐字节相同，0.78 vs 0.04——
   结局由"注入 × 模型采样"联合决定；5×3 重跑审计完成前定量支柱空缺。
4. **评分罚则贡献（口径因子）**：D7 x2 重复集 5 道 0 分中 1 道（task_00023，score_simple=0.41）
   系交卷被 hybrid 罚则清零；含 held-out 共 7 道 0 分、2 道（00023/00011）属此类。
   −0.177 部分幅度来自评分口径（score_simple 口径 −0.128 佐证）。
5. **门控全盲（工程面，非记忆因果）**：所有 211 次请求级未成功、49 次任务级失败均未被升级捕获；升级 0 次不等于零失败。
6. **数据完整性（Q4/B4）**：issue-022 OOM 通过 resume 恢复，无分数污染；issue-023 402 错误发生在评分 API 调用前，无评分污染；`audit.json` 与 `run.jsonl` 一致性需正式 checksum 归档。
