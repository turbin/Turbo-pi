# issue-014: 字面检索（bm25）对措辞差异不敏感——泛化测量受限（延后演进项）

- 状态：**deferred（用户 2026-08-14 裁决：登记在案，全部实验完成后由用户确认是否进一步演进）**
- 报告：2026-08-14（承接概要设计 v2 §3.4 边界声明 5）
- 影响面：`packages/agent-server/src/retrieval.ts`（buildFtsQuery / cosineScore）；判据②（新任务泛化）的测量灵敏度

## 问题

检索无语义解析层：FTS5 bm25 召回 top-24 后余弦重排，匹配本质是字面词项重合。新任务与卡片措辞不同但语义相同时召回失败（漏召），措辞相似但语义无关时误召。判据②"新任务升级率 <20%"测量的是"在字面可匹配的新任务上的泛化"，而非真泛化——测量口径受此约束，报告的泛化结论须注明。

## 影响评估

- 不阻断实验：判据②仍按绝对阈值验收，口径偏差对内（双臂同检索器）对称，A/B 差分有效
- 影响归因粒度：F3 的 domain 过滤只能防跨域字面串扰，管不了同域内的语义错配
- C 阶段实测检索命中 100%（E5 飞轮 6231/6231），但该口径是"有命中"而非"命中正确"

## 演进方向（届时由用户定夺）

语义检索（embedding 召回或混合召回）、查询扩展、或保持字面检索并显式声明口径。决策时点：9B 全量重跑批 + ALFWorld 阶段全部完成后，用户依据泛化数据决定是否立项。
