## 原文要点（用户提供，7 条）

EWC 作用于权重无法直接照搬，但架构思想可映射到记忆系统设计：
1. **重要性加权巩固**（←Fisher 信息）：给记忆打重要性分数（因果贡献、检索命中频率、决策分叉关键性），巩固优先高分、淘汰优先低分
2. **弹性锚定而非冻结**（←二次惩罚 vs L2）：核心经验作强先验注入但允许新证据以与重要性成反比的速率修正；避免完全不可变与完全可覆写两个极端
3. **合并蒸馏**（←二次惩罚之和仍为二次惩罚）：同类轨迹定期蒸馏为一条巩固记忆，保留"均值"（核心做法）与"方差"（适用边界）
4. **双时间尺度记忆**（←经验回放+EWC）：短期/情景层存原始轨迹供即时检索；长期/巩固层存蒸馏稳定知识，写入慢修改难
5. **情境自动推断**（←HMM+Forget-Me-Not）：按任务/情境组织而非时间平铺；写入打情境标签，执行先推断情境再检索
6. **轻量任务专属层**：共享通用记忆之上保留项目/任务专属覆盖层，随任务切换启用
7. **记录不确定性**（←论文自陈最大局限）：巩固记忆必须附带置信度元数据，随新证据下调
