## 8. 任务功能与考察能力（问答）

任务形态：带工作区夹具的交付物驱动场景（预置配置/日志/数据/记忆文件），hybrid 评分（automated + LLM judge），单任务 1800 秒。

按 8 大类的功能与考察点：

1. **工作流与智能体编排（21）**：创建可复用 skill、多智能体架构、DSL/工作流脚本——考察"先建 skill 再用 skill"元能力、长程规划、文档化合规。
2. **系统运维管理（20）**：故障排查（API key/npm start/网关崩溃）、健康检查、状态报告——考察日志/配置根因定位、工具调用正确性（对应门控四规则）、恢复计划可执行性。
3. **知识与记忆管理（15）**：记忆文件总结、记忆系统诊断、知识库结构化——考察跨文件一致性核对（如 00002 的 interval 不一致）、碎片知识结构化、接地性（禁占位符）。
4. **数据分析建模（10）**：DID 回归、统计评估、损益分解、SPARQL——考察计算正确性、结构化 JSON 输出、方法选择。
5. **金融量化（10）**：套利监控、动量回测、模拟盘引擎——考察抗数据陷阱（00075 的拆分复权/重复行/隐藏规则三坑）、清洗→计算→双交付物链路。
6. **安全（9）**：凭证审查、代码审计、提示注入防御——考察安全意识、信任模型判断力、审计覆盖面。
7. **通信与日程（8）**：进度汇报、调度优化、cron 诊断——考察约束优化与定时任务配置正确性。
8. **检索研究（7）**：文献修复、竞品分析、算法讲解——考察信息综合与教学式表达准确性。

横切能力维度：指令遵循与交付物完整性（automated 检查）、隐藏信息发现（陷阱/不一致/隐藏规则，judge 重点）、工具调用格式（升级率直接来源）、长程不跑偏（30 分钟多交付物）、输出格式合规（JSON/YAML/frontmatter）。

在经验学习评估中的作用：重复集测记忆复用（D1 踩坑 D7 不升级，判据① ≤5%）；新任务测经验迁移（同类新任务复用方法/Guard 卡，判据② <20%）；任务分数为归因奖惩（演进方案 2）的输入信号。
