## 3. 归因分析（模型能力 vs harness 学习）

预注册公式：harness 学习增益 =（实验臂 D7 − 实验臂 D1）−（对照臂 D7 − 对照臂 D1）

| 臂 | D1 | D7 | Δ |
|---|---|---|---|
| 实验臂（带记忆） | 0.567 | 0.532 | −0.035 |
| 对照臂（无注入） | 0.507 | **0.369** | **−0.138** |

**学习增益 = −0.035 − (−0.138) = +0.103（+10.3pp）**

解读：
- 对照臂 D7 相对 D1 下滑 0.138——**无记忆时同任务复跑表现自发劣化**（环境/任务顺序漂移、judge 方差或其他未控因素；D1 同日双臂差 ±0.04 的噪声地板不适用于跨日）
- 实验臂借助经验库**抵消了大部分自发劣化**（仅 -0.035）——这是"记忆有效"的第一个对照级证据
- **诚实边界**：n=20、对照臂单点测量、对照下滑本身未定性（若 D7 对照下滑是系统性漂移而非噪声，+10.3pp 会高估真实增益）；卡片"提升绝对表现"仍无证据（实验臂未超 D1 基线）
